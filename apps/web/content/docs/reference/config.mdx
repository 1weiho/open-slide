---
title: open-slide.config.ts
description: Workspace-level configuration.
---

The config lives at the workspace root and is fully optional — every field
has a sensible default.

```ts title="open-slide.config.ts"
import type { OpenSlideConfig } from '@open-slide/core';

const config: OpenSlideConfig = {};

export default config;
```

## Schema

| Field       | Type                   | Default                          | Description                                              |
| ----------- | ---------------------- | -------------------------------- | -------------------------------------------------------- |
| `base`      | `string`               | `'/'`                            | Base public path for subpath hosting (leading + trailing slash). |
| `slidesDir` | `string`               | `'slides'`                       | Folder that contains your decks.                         |
| `themesDir` | `string`               | `'themes'`                       | Folder that holds theme markdown + demo files.           |
| `assetsDir` | `string`               | `'assets'`                       | Folder for global assets shared across decks.            |
| `port`      | `number`               | first free port from 5173 upward | Dev server port.                                         |
| `build`     | `OpenSlideBuildConfig` | all toggles on                   | Build-time UI toggles (see below).                       |
| `locale`    | `Locale`               | —                                | Deprecated — seeds the runtime UI language until one is picked in-app. |

### `build`

Every toggle is on by default and only takes effect in the static build; the
dev server always shows the full UI.

| Field               | Type      | Default | Description                                              |
| ------------------- | --------- | ------- | -------------------------------------------------------- |
| `showSlideBrowser`  | `boolean` | `true`  | Show the deck index (the slide browser) in the static build. |
| `showSlideUi`       | `boolean` | `true`  | Show on-canvas UI (toolbar, hints) in the static build.  |
| `allowHtmlDownload` | `boolean` | `true`  | Show the export menu (HTML, PDF, image PPTX) in the static build. |

## Common recipes

### Public share

Hide the slide browser, on-canvas UI, and export menu with the `build`
toggles — see [Export](/docs/core-feature/export) for the annotated
example.

### Host under a subpath

Set `base` to deploy the build under a sub-directory instead of the domain
root — GitHub Pages project sites, a reverse-proxy folder, an intranet path.
Use a leading and trailing slash:

```ts
const config: OpenSlideConfig = {
  base: '/my-slides/',
};
```

The value is passed straight to Vite's `base` and to React Router's
`basename`, so client-side navigation matches the deployed path.

### Organizing many decks

`slidesDir` is a single path and decks must sit directly inside it
(`slides/<id>/index.tsx` — nested folders are not discovered). To group
decks, use the in-app sidebar folders (stored in `slides/.folders.json`).
